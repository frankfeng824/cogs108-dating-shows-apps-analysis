# Project notebooks

The team's working Jupyter notebooks from our UCSD COGS 108 final project (Spring 2026), reproduced from the course's private group repository.

**Team:** Anisha Ramesh, Alisa Liao, Junyou Feng, Derek Xu

| Notebook | What it covers |
|----------|----------------|
| `00-ProjectProposal.ipynb` | Project proposal: research question, hypothesis, planned data sources |
| `01-DataCheckpoint.ipynb` | Data collection and cleaning checkpoint |
| `02-EDACheckpoint.ipynb` | Exploratory data analysis: distributions, trends, visualizations |
| `03-FinalProject.ipynb` | Final analysis: OLS regression models, findings, limitations |

The 8 CSV files in this folder are the raw datasets used in the analysis.

For the project narrative, methods, and individual contributions, see the main [README](../README.md).
